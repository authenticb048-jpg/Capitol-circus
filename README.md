# CAPITOL CIRCUS — website starter

Static website starter for an independent American political-satire project.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive circus-inspired design
- `script.js` — manually curated Trending and Latest feeds
- `assets/` — reserved for future original/licensed images

## Preview
Open `index.html` in a modern browser. No build tools, wallet connection or server are needed.

## Add public X posts manually
Edit `script.js`. Add entries to `trendingPosts` and/or `latestPosts` using the example object comments. Verify the post URL, author, date and engagement figures against the original post. Do not imply an author endorses or is affiliated with this project unless they explicitly confirm it.

Only HTTPS links on X/Twitter domains are rendered as source links.

## Publishing later
This package is not published. GitHub Pages is one possible free static-hosting option, but publishing is a separate action and has not been performed.

## Current scope and safeguards
- No token created.
- No wallet connected.
- No payment, transaction or deployment performed.
- Feed is manual; no X API key or paid service is included.
- The eagle mascot is represented with an emoji and CSS artwork in this starter. Replace it with an original or properly licensed graphic if desired.
- CAPITOL CIRCUS is satire, not a news organization, government site or political campaign.
